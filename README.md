# Python and Java Learning Repository

This repository is a place to learn, practise, and share programming examples in **Python** and **Java**. It is managed by **Sriyans and Devashish**, students in **Class 11 at St. Xavier's School**.

## What you'll find here

- Beginner-friendly programs and experiments
- Practice with programming basics such as loops, conditions, and user input
- Examples that we can build on as we learn more

## Run the examples

### Python

```bash
python3 welcome.py
```

### Java

```bash
javac world.java
java mains
```

## About

This is a student learning project. The programs may change as we practise and explore new ideas, and we welcome suggestions and constructive feedback.
